Importar backup do modo local

Selecione o arquivo JSON exportado pelo botão Backup JSON da FAVMED local. Os registros serão enviados diretamente do seu navegador para o Supabase.

A importação combina os pacientes pelo identificador, preservando registros que já existam na nuvem. Não envie arquivos de pacientes por este formulário de conversa; a transferência ocorre diretamente entre o navegador e o Supabase. PDFs locais não estão dentro do backup JSON e precisarão ser anexados novamente.
